Forced Subtitles

Fills in missing subtitles from OpenSubtitles.com: forced subtitles for foreign dialogue, and full subtitles for foreign-language films.

OpenSubtitles.com account

Checking…
Leave blank to use the login from the OpenSubtitles plugin, if you have it installed.
Advanced: custom API key
Only needed if this build has no built-in key. Create one at opensubtitles.com → Profile → API consumers.

What to download

Three-letter code, e.g. eng.
Audio in this language: downloads a forced subtitle (foreign dialogue only) if the video has none. If OpenSubtitles has no forced subtitle for it, nothing is downloaded.
For example a French film with no English subtitle track.

Libraries

Pick the libraries to check. If none are ticked, every library is checked.

Where to save

Jellyfin only reads subtitles from these places. Choose "next to the video" if other players (VLC, Plex, …) also need them.

When to run

Full checks run from the "Download missing forced subtitles" scheduled task (daily at 3am by default, under Scheduled Tasks → Subtitles).

Matching

Guarantees sync but finds far fewer subtitles.
